# Idées

Pistes communes à tous les jeux, puis idées propres à chacun. Les feuilles de route détaillées
restent dans le dossier de chaque jeu.

## Pour tous les jeux

- **Promotion croisée** : une carte « Nos autres jeux » dans les réglages ou l'accueil, sans pub
  payante.
- **Statistiques anonymes** communes : Ça Roule envoie déjà ses événements à PostHog (hébergement
  européen, sans cookie, désactivables). Les extraire dans le kit pour les autres jeux.
- **Musique** enregistrée par un musicien, pour remplacer la musique synthétisée.
- **Calendrier d'événements** : rallye du week-end, défi de la semaine, avec le même système de
  rappels.
- **Sauvegarde dans le nuage** (compte Google Play Jeux ou iCloud) pour changer de téléphone sans
  perdre sa progression.

## Mélo Pop

- Plus de types d'obstacles : cadenas, cases vides.
- Musique et sons enregistrés, pour remplacer les sons synthétisés.
